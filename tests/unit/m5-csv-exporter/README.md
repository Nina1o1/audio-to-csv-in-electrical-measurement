# M5 CSV 导出测试

`csv-exporter.test.ts` 验证两个公开方法：固定八列、不导出 ID、测量值带标准单位、整批运行时校验、CSV 转义、公式防护、CRLF/BOM、文件名、错误代码、输入不变性及重复操作。

`browser-download.test.ts` 使用浏览器边界替身验证 UTF-8 Blob、下载触发、成功后的延迟资源清理、失败清理及多次下载资源隔离。测试不宣称已验证真实浏览器落盘行为。

回归覆盖全部 C1 控制字符后的公式前缀，两个公开方法均断言防护结果。非法字段用例单独校验并使用不同 ID 的周围记录，避免重复 ID 掩盖字段校验退化。下载链路测试不 mock 业务模块或下载适配，直接核对实际 Blob 的完整 UTF-8 字节及资源释放，覆盖默认 BOM 和禁用 BOM。

运行：`npm test -- tests/unit/m5-csv-exporter`。
