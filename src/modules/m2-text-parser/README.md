# M2 文本解析

将单次 TranscriptSegment 解析为稀疏 ParseResult；不读取或修改草稿。

入口为 `createTextParser(): TextParserModule`，公开方法为同步的
`parse(segment: TranscriptSegment): ParseResult`。结构非法抛 TypeError；空文本返回 `{}`。

字段、结果词和单位词表遵守 Public Interface。测量值在本模块内换算为 mΩ、MΩ、V，
只输出 number。无单位默认标准单位；绝缘电阻支持千欧乘0.001。微欧、kΩ、错配单位和未知单位均不作为有效更新。
单位符号区分大小写，数词与单位完整匹配，不接受有效前缀截取，不主动舍入。
测量候选中的换行保留为空白，数值后换行不会丢失单位或范围；不拼接被空白拆开的数词。
英文结果词只折叠 ASCII 字母大小写，中文词精确匹配，不接受 ſ/ß 等非词表字符的兼容转换。

本次实现采用用户已确认的补充约定：

- 字段连接词限“是”“为”“改成”“改为”“：”“:”及空白。
- 阿拉伯小数须数字开头且小数点后有数字；不接受正号。
- 中文位值支持尾位省略：一百二为120，两百五为250；一百零二为102。
  中文原始值仍不得超过1000，单位换算结果不受该上限限制。
- 固定的“，不对，是数值[单位]”（逗号也可使用半角）仅纠正紧邻前一明确命名的测量字段。
  其他字段或无关语句阻断关联；纠正不连续继承省略字段的上下文，不跨调用关联。
  上下文要求完整数词与已识别的单位结构；数值无效（如负三）仍可归属明确，
  含无关尾文的数字前缀不能建立上下文。原候选与纠正候选各自独立校验有效性。
- 数词、标识符、结果词和单位须完整匹配；无关尾文应以标点分隔，有歧义时跳过候选。

字段按文本位置处理，只有有效候选覆盖此前值。内部不保留草稿或转写历史，
不读取存储、不导入 Vue、不操作 DOM、不调用其他业务模块。

`chinese-number.ts` 仅为 M2 内部的中文数词纯函数，不扩展共享模型或模块公开接口。

换行、结果词折叠及受限纠正规则已同步至 Public Interface 第3节。

H01–H17扩展已同步：料号与耐电压分别映射原partNumber与withstandVoltage；
PASS、FAIL、不通过仍要求本次有效字段上下文才接受紧邻的独立结果词。合法耐压值与完整单位可附着结果词；
结果省略纠正只作用于紧邻的有效结果。无关句、其他字段及调用边界会阻断关联。
不会从测量数值自动产生结果，也不会全局搜索“合格/通过”。

2026-10-29 专项修复已确认并同步 Public Interface：

- 工单前允许口头语；相邻明确字段无需标点。标识符分句的逗号与测量数字分隔防护分别处理。
- 有限重复字段名使用同一词表：工工单/工工工单/工单单、料料号/料号号；
  最早位置、同位置最长优先并完整消耗字段名，不全局去重、不改变编号重复字符。
- “6号/六号”仅在紧随完整工单且后接完整ASCII字母开头料号时建立边界，
  中间仅允许空白或分句标点；不全局替换、不跨字段/调用继承、不猜测不完整或多义切分。
- 正式增加“检测结果”别名；完整独立分句“合格/不合格”无需已有记录上下文。
- “通过”从所有结果触发路径移除；完整合法耐压数值与单位附带“通过”时仅输出电压，
  不建立结果纠正目标，不剥离通过率等任意尾文。PASS/FAIL/不通过保留原有作用域。
