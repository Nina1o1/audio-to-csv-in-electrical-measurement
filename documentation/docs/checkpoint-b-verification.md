# Checkpoint B 验证

## 实现范围

复用现有 M1–M5，在 App 协调层完成最终片段 → M2.parse → M3.applyParseResult；M3.getDraft 和既有订阅提供草稿快照。M1–M5 的 Public Interface、Data Models、标准单位、持久化格式均未改变。

- 实时快照不解析，不累计转写历史；空白片段及空解析不调用草稿更新。
- M1 保证每段完成一次、识别去重及旧物理连接隔离；App 仅消费当前录入上下文一次，保存成功、确认删除、退出语音及卸载后失效。不根据相同文本去重不同录入。
- M1 通知期间不嵌套业务变更，App 在微任务中检查当前上下文并路由命令／合并字段。STOP_INPUT 不负责解析，完成事件是唯一解析入口。
- M2、M3、M4 均同步；真实异步风险来自 M1 启动／收尾、微任务及代理登录。无额外任务队列或状态框架。
- 按钮保存／删除在当前录入收尾后执行一个待处理请求；解析失败取消该请求。确认／保存期间拒绝新录入及语音修改。
- M4 保存失败、pending 复用、未知结果核对、历史 CRUD、查询、选择和 CSV 继续使用已有流程。

## 真实麦克风清单（尚待人工执行）

前提：同源 HTTPS 页面与已有 `/api/m1/*` 代理已部署，讯飞配置有效；使用桌面 Chrome／Edge，允许必要的浏览器语音服务网络访问。代理部署参考 infrastructure/m1-speech-proxy/README.md。没有提供／调用真实凭据，自动化不代表真机验收。

- [ ] 展开“语音代理访问”，用共享访问口令登录；检查登录成功且口令输入框清空。
- [ ] 开始监听 → 说“开始输入” → 等待录入就绪 → 说完整示例数据 → 说“结束输入”；检查状态、实时文本和最终草稿。另测按钮结束及停顿自然完成。
- [ ] 完整示例：“工单A2301，料号C-045，接触电阻12毫欧，绝缘电阻500兆欧，耐电压1500伏通过，合格”。核对六项字段和标准单位。
- [ ] 新一段说“接触电阻改成15毫欧”；仅对应字段变化，其他字段保留。
- [ ] 手动改料号，再语音补充／修正测量值；确认操作同一份草稿。
- [ ] 说“保存” → “修改” → “保存” → “确认保存”；确认一次写入历史、清空草稿和本次文本，刷新后历史仍在。
- [ ] 说“删除” → “保留”；草稿不变。再说“删除” → “确认删除”；只清空草稿，历史不变。
- [ ] 录入未结束时点击保存／删除；等待最终文本合并后才显示确认。重复点击不重复执行。
- [ ] 拒绝麦克风权限、关闭设备或断网；错误可理解，手动草稿不丢失。中断仅保留已确认文本，回到 IDLE 后可重新启动。
- [ ] 录入中说含“保存／删除”的普通正文，不触发草稿操作；确认弹窗期间尝试开始录入，应拒绝且保留草稿。
- [ ] 关闭／重开页面，检查麦克风资源释放及没有重复监听；代理退出后重新录入应要求有效访问会话。
- [ ] 回归手动校验／保存失败重试、历史查询／编辑／删除、选中与全部 CSV 导出。

注意：M1 的 RECORDING 状态包含音频及代理启动阶段，现有公开接口没有独立“音频就绪”事件；首次权限和冷启动延迟不能由 App 伪装成就绪保证。
